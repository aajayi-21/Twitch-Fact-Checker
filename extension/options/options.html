Checking backend…

    The gate runs ~300 cheap calls/hour (Claude Haiku, or locally via Ollama); verification needs web search, so it runs on Anthropic or OpenRouter. Models are checked when you Apply: Anthropic ids (e.g. claude-haiku-5-5) against Anthropic's model list, OpenRouter slugs against its live catalogue (openrouter.ai/models).

    Must start with ws:// or wss://. Applies the next time capture starts.

    Claim sensitivity

    Higher sensitivity fact-checks more borderline claims and uses more API quota. Applies live to a running session.

    Topics to fact-check

    Claims outside the checked topics are ignored. All topics are on by default. Changes apply instantly — even mid-stream.
